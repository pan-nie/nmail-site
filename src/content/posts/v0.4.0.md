v0.4.0 发布了。继上周「AI 总管家全面重写」之后，这一版把 Agent 化的最后一批拼图补齐：**AI 更懂你、更稳、更能兜底，也终于能被一句话从外面使唤。**

## 总管家更懂你

- **跨会话记忆**：你明说过的偏好与纠正（“汇报要简洁”“周报都发给某某”）会存进**本机**记忆库，下次对话自动带上，不用反复交代；设置-AI 用量-记忆 可查看/编辑/删除，数据不出机器。
- **拿不准先问你**：信息不足或有多义时，AI 会暂停并出「向你确认」卡——常见选项按钮 + 自由输入，你答完它带着答案继续跑，不自作主张猜错方向。
- **内置工作流技能**：周报摘要、跟进提醒、批量归档策略、报销发票整理四个方法论开箱即用，说一句「做个本周周报」就开干。

## 长任务更稳

- **触顶先小结再暂停**：步数/时间预算耗尽时，AI 先给一段进度小结（做了什么、到哪一步、建议下一步）再停下来等你，而不是无声断掉；点「继续执行」接着干，刷新后入口也还在。
- **不吹牛收尾**：最终回答若声称「已发送/已归档/已删除」但执行记录里没有对应动作，系统当场纠正它改口——收尾结论以执行记录为准，防幻觉。
- **只读操作并行**：同批的查、搜、读类调用并行执行，多步侦查类任务明显更快。

## 每天多一份「今日建议」

**AI 晨报**（设置里开关）：总管家每晨定时主动巡一遍邮箱，写一份更有人味的简报——昨夜来了什么、哪些需要今天处理、建议的顺序；作为独立区块显示在每日摘要页底部，通知中心展开即读全文。开启当天不再重复生成常规 AI 综述，省一次调用。

## 从外面使唤它

- **CLI 总管家通道**：`nmail-cli agent ask "把收件箱里的营销邮件都归档"` 一条命令委托内置总管家，审批/审计/每日限额闭环原样生效——外部 agent、脚本、快捷指令都能安全地一句话交办。
- CLI 新增 `folders list`（移动目标有处可查）与版本协商（CLI 落后时自动提示升级）。

## 安全两处加固

公网隧道场景下管理面默认拒绝来自 Cloudflare 边缘的请求（SSH 隧道 / Tailscale 不受影响，对外 API 持 Key 调用照常）；数据目录文档明确警示**不要放进 iCloud/OneDrive 等云盘同步范围**，避免数据库与密钥被同步层锁坏或外流。

## 升级方式

```bash
brew upgrade pan-nie/nmail/nmail    # macOS (Apple Silicon)，先 brew trust pan-nie/nmail
uv tool upgrade nmail-app             # PyPI 常驻安装
```

Windows 用户到 [Releases](https://github.com/pan-nie/Nmail/releases) 下载新版 exe 覆盖；命令行用户重跑 `uvx --from nmail-app nmail` 即可（若未取到新版，先 `uv cache clean nmail-app`）。旧数据自动迁移，无需手动操作；开着旧标签页的话**强刷一次**（Cmd/Ctrl+Shift+R）。
