v0.3.0 发布了。这是本轮大改版的落地版，围绕一个目标：**邮箱里的例行事务，AI 替你做；做不做，你说了算。**

## 这次有什么新东西

- **邮件 = 文件**：左侧文件夹树 + 多选/拖拽/右键/快捷键，新建、重命名、删除服务器文件夹随手就来；归档改为每账号真实的服务器端 Archived 文件夹，网页端邮箱里同样可见。
- **AI 总管家 2.0**：从问答升级为对话 Agent——「把上周的营销邮件归档，然后给老张回一封」一句话完成；默认审批模式每步可改可拒，AI 专属邮箱可开自动模式（收件人白名单 + 每日限额 + 全量审计 + 一键撤销）。
- **草稿合并**：AI 待审草稿与手写草稿并成一个「草稿」视图，AI 稿也能改后发、定时发。
- **通讯录全面改版**：从一张平铺表升级为 Thunderbird 式双栏管理——左树四个智能视图（所有联系人 / 自动采集 / 手动添加 / 未分组，带计数）+ 自定义联系组（新建、右键重命名、删除），右侧列表 ⇄ 详情双态，支持搜索、新增（含手机号）、批量删除；联系人可归入多个组、同邮箱多账号自动聚合为一行，点联系人直达写信台并带入收件人。
- **自动采集开关**：收发信往来的地址默认自动入册，不需要时左树顶部一键关掉（已入册的保留，手动增删和写信补全不受影响）。
- **登录零配置**：Gmail / Outlook 用内置公开客户端凭证一键授权，自建客户端随时覆盖。
- **对外 API**：`/api/ext/v1` + API Key + scope 分级，快捷指令、Raycast、n8n 都能接；远程设备走你自建的隧道。
- **界面统一**：砍掉侧栏，邮件为唯一基座，其余页面小按钮点击开页签；全站字号统一跟随三档设置。

## 一批体验修

- **授权码所见即所存**：账号配置编辑器预填当前授权码 + 小眼睛显隐，改码直接覆盖保存，不再「保存了但不知道存了什么」。
- **改服务器不用删号**：SMTP/IMAP（授权码）账号的服务器与端口可以直接编辑——保存前自动试连，改完清空该账号本地邮件并后台重同步，换服务商端口再也不用删号重加、丢账号设置。
- 时间显示统一（UTC+8 晚间的往来不再显示成前一天）、设置页加宽（896px → 1152px）、通讯录列表横向可滚不再裁切。

## 升级方式

```bash
brew upgrade pan-nie/nmail/nmail    # macOS (Apple Silicon)，先 brew trust pan-nie/nmail
uv tool upgrade nmail-app             # PyPI 常驻安装
```

Windows 用户到 [Releases](https://github.com/pan-nie/Nmail/releases) 下载新版 exe 覆盖（winget 渠道审核中，合入前不可用）；命令行用户重跑 `uvx --from nmail-app nmail` 即可（若未取到新版，先 `uv cache clean nmail-app`）。旧数据自动迁移（新增联系组两张表），无需任何手动操作。
